# هزارتو

یه اپ اندروید که کل گوشی رو از شبکه‌ی **Lokinet** رد میکنه. Lokinet یه شبکه‌ی پیازی شبیه Tor هست که روی هزاران نود داوطلب میچرخه و به کلادفلر و سرور شخصی هیچ ربطی نداره.

الان نسخه‌ی آزمایشیه. هدفش فقط اینه که ببینیم روی نت ما وصل میشه یا نه:

- همه‌ی VPNهای دیگه رو خاموش کن
- اتصال رو بزن و ۲ تا ۳ دقیقه صبر کن
- بعد «تست خروجی» رو بزن

اگه چیزی کار نکرد، از قسمت لاگ «کپی» رو بزن و بفرست.

موتورش Lokinet نسخه‌ی 0.9.15 هست با یه وصله‌ی کوچیک برای اندرویدهای جدید (`engine/patches`). لایسنس GPL-3.0، مثل خود Lokinet.
