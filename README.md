# هزارتو

یه اپ اندروید که کل گوشی رو از شبکه‌ی **I2P** رد میکنه. I2P یه شبکه‌ی ناشناس با هزاران روتر داوطلبه، و ترافیک اینترنت معمولی از خروجی عمومی **StormyCloud** (یه سازمان غیرانتفاعی) میره بیرون. نه سرور شخصی میخواد، نه دامنه، نه کلادفلر.

نسخه‌ی آزمایشیه:

- همه‌ی VPNهای دیگه رو خاموش کن (اپ رسمی i2pd هم اگه داری ببندش)
- دکمه رو بزن و صبر کن. **بار اول ممکنه تا ۱۰ دقیقه طول بکشه** چون باید شبکه رو پیدا کنه، دفعه‌های بعد اطلاعات شبکه رو داره
- وقتی نوشت «وصلی»، همه‌ی اپ‌ها از هزارتو رد میشن

اگه وصل نشد یا چیزی کار نکرد، «کپی گزارش» رو بزن و بفرست.

## چطوری کار میکنه

```
اپ‌ها ← تونل اندروید ← hev-socks5-tunnel ← پل SOCKS→HTTP ← i2pd ← تونل‌های I2P ← خروجی StormyCloud ← اینترنت
```

- اسم سایت‌ها توی خروجی پیدا میشه، نه با DNS فیلترشده‌ی داخل
- اپ قبل از روشن کردن تونل، یه صفحه‌ی https رو از همین مسیر باز میکنه و تا اون جواب نده «وصلی» نشون نمیده
- UDP (مثل تماس صوتی بعضی اپ‌ها) از این مسیر رد نمیشه و اپ‌ها خودشون میرن سراغ TCP

موتور، کتابخونه‌ی آماده‌ی [i2pd-android](https://github.com/PurpleI2P/i2pd-android) نسخه‌ی 2.61.0 هست (BSD-3) و تونل محلی [hev-socks5-tunnel](https://github.com/heiher/hev-socks5-tunnel) (MIT). کد خود اپ GPL-3.0.
